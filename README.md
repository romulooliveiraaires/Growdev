# Desafio SQL — Blocos A até I

Este repositório contém os scripts SQL organizados por blocos temáticos (A a I) para o desafio proposto.

## 📂 Estrutura dos arquivos

- `bloco_A.sql` — SELECT básico
- `bloco_B.sql` — JOINs
- `bloco_C.sql` — Funções agregadas + GROUP BY + HAVING
- `bloco_D.sql` — Subqueries
- `bloco_E.sql` — CASE WHEN
- `bloco_F.sql` — CTE / tabela temporária
- `bloco_G.sql` — Views
- `bloco_H.sql` — Procedures/Functions parametrizadas
- `bloco_I.sql` — Window functions

 ## 🔍 Principais insights

- Os scripts demonstram habilidade em SQL, joins, agregações, subqueries, CTEs, window functions, views e functions.
- As consultas estão estruturadas para facilitar a análise de vendas, desempenho por vendedor, por produto, métricas de frete, composição de faturamento e KPIs essenciais para o negócio.
- O uso de funções parametrizadas e views avançadas permite reuso e agilidade para análises futuras.
